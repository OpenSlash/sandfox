# Roadmap

Sandfox is a local-first desktop client for managing `sing-box` profiles, proxy policies, DNS, rules, and privileged service workflows.

## Current

- Finish target-host verification for macOS, Windows, and Linux privileged service lifecycles.
- Complete Linux package validation across AppImage, DEB, RPM, and Arch formats.
- Improve setup diagnostics when `sing-box` is missing, unsupported, or incompatible.
- Expand regression coverage for profile parsing, rule conversion, and generated configuration.

## Next

- Publish the first tagged release with per-platform artifacts and checksums.
- Add platform-specific installation and troubleshooting guides.
- Improve import errors, subscription validation, and safe handling of private configuration.
- Make helper status and failure reasons easier to inspect.
- Add screenshot and feature documentation for profile, policy, DNS, rules, logs, and settings areas.

## Exploring

- Automated release publication with signed artifacts.
- Profile diagnostics and rule coverage reports.
- Better logs and correlation between UI actions, generated configuration, and core events.
- Accessibility and keyboard navigation improvements.

The roadmap describes intent, not a commitment to a delivery date. Platform-specific work may be re-prioritized when upstream dependencies, APIs, or validation environments change.

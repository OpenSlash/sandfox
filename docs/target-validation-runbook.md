# Target Validation Runbook

Use this runbook to close the remaining Rover parity gates that cannot be proven by source inspection or local unit tests.

## Evidence Directory

Create a directory that will hold target-host JSON evidence:

```sh
mkdir -p /tmp/sandfox-rover-evidence
```

After collecting evidence, run the completion audit from the Sandfox project root:

```sh
export PATH="$HOME/go/bin:$PATH"
SANDFOX_AUDIT_EVIDENCE_DIR=/tmp/sandfox-rover-evidence wails3 task audit:rover
```

Evidence files must be generated by the current validators and include schema `sandfox-rover-target-v1`. Helper and package artifacts also record SHA-256 hashes for traceability.

The evidence bundle task refreshes `current-helper-safe.json` in non-mutating mode. Its `mutating-service-cycle` check is marked `skipped: true`; it is useful as current-host helper evidence but does not replace the required `macos-service.json`, `windows-service.json`, or `linux-service.json` lifecycle evidence.

To print the current target-host commands from the project itself, run:

```sh
export PATH="$HOME/go/bin:$PATH"
wails3 task audit:rover:commands
```

To write the command file, refresh the current safe helper evidence, write the pending target evidence manifest, and package the current evidence directory, run:

```sh
export PATH="$HOME/go/bin:$PATH"
wails3 task audit:rover:evidence-bundle
```

## macOS RoverService Lifecycle

Run on a macOS host with the packaged app available. The mutation validator must run as root because the helper installs a LaunchDaemon under `/Library`.

```sh
sudo env \
  PATH="$HOME/go/bin:$PATH" \
  SANDFOX_VALIDATE_SERVICE_MUTATION=1 \
  SANDFOX_VALIDATE_EVIDENCE_OUT=/tmp/sandfox-rover-evidence/macos-service.json \
  wails3 task validate:roverservice
```

Expected audit gate:

- `macos-privileged-service-real-run`

The command installs, checks installed/running state after install, stops, checks installed/not-running state after stop, starts, checks installed/running state after start, uninstalls, and checks not-installed/not-running state after uninstall. The evidence also records helper/source mtimes and requires the helper to be newer than key app/helper source files.

## Windows RoverService Lifecycle

Run on a Windows host after building or installing the Windows package. Start PowerShell as Administrator before running the validator.

```powershell
$env:SANDFOX_VALIDATE_SERVICE_MUTATION="1"
$env:SANDFOX_VALIDATE_EVIDENCE_OUT="C:\sandfox-rover-evidence\windows-service.json"
$env:Path="$env:USERPROFILE\go\bin;$env:Path"
wails3 task validate:roverservice
```

Expected audit gate:

- `windows-service-real-run`

The command installs, checks installed/running state after install, stops, checks installed/not-running state after stop, starts, checks installed/running state after start, uninstalls, and checks not-installed/not-running state after uninstall. The evidence also records helper/source mtimes and requires the helper to be newer than key app/helper source files.
The validator does not require the Unix `file` command on Windows; it falls back to file existence and size for the helper binary check.

## Linux Package Artifacts

Run on Linux or on a host with working Docker.

```sh
export PATH="$HOME/go/bin:$PATH"
SANDFOX_VALIDATE_LINUX_PACKAGE_MUTATION=1 \
SANDFOX_VALIDATE_EVIDENCE_OUT=/tmp/sandfox-rover-evidence/linux-package.json \
wails3 task validate:linux-package
```

On macOS or another non-Linux host with Docker, run the Linux package chain inside the `wails-cross` image:

```sh
export PATH="$HOME/go/bin:$PATH"
SANDFOX_VALIDATE_LINUX_PACKAGE_MUTATION=1 \
SANDFOX_LINUX_PACKAGE_DOCKER=1 \
SANDFOX_VALIDATE_EVIDENCE_OUT=/tmp/sandfox-rover-evidence/linux-package.json \
wails3 task validate:linux-package
```

To avoid GitHub download failures during AppImage generation, pre-place the AppImage tooling cache before running the Docker target:

```sh
mkdir -p build/linux/appimage/cache
curl -L -o build/linux/appimage/cache/linuxdeploy-aarch64.AppImage \
  https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-aarch64.AppImage
curl -L -o build/linux/appimage/cache/AppRun-aarch64 \
  https://github.com/AppImage/AppImageKit/releases/download/continuous/AppRun-aarch64
```

Expected audit gate:

- `linux-full-package-environment`

The evidence must include successful AppImage, DEB, RPM, and Arch Linux package artifact checks. The validator also records artifact mtimes and requires the package artifacts to be newer than key app/helper source files.

## Completion

After all four evidence files exist, run:

```sh
export PATH="$HOME/go/bin:$PATH"
SANDFOX_AUDIT_EVIDENCE_DIR=/tmp/sandfox-rover-evidence wails3 task audit:rover
```

Only mark Rover parity complete when this audit passes without incomplete gates.
